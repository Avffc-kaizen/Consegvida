# ConsegVida

Segurança do ser humano. Evolução física, mental e espiritual. Plano de 30 anos.

Repo público: https://github.com/Avffc-kaizen/Consegvida  
Manifesto: https://www.youtube.com/watch?v=TkyLy-kIGhE  
Domínio: https://www.consegvida.com (503 + certificado inválido nesta data)

## Filosofia

Fonte: manifesto *Plano para proteger o mundo*. Não inventar doutrina. Fases 2–5 existem no vídeo e só aparecem quando o visitante estiver pronto.

| Eixo | O que protege | Origem no manifesto |
| --- | --- | --- |
| Físico | Corpo e entorno | Ambiente imediatamente mais seguro. Zero morte por doença evitável. |
| Mental | Propósito e foco | Consciência do próprio propósito. 99% realizam o que se propõem. |
| Espiritual | Consciência e causa | Protege-te, sê consciente, só existe onde estás no mundo. Causa maior que partido, classe ou religião. |

Fase 1 — Despertar. Quatro objetivos: engajar o Brasil; tornar cada pessoa consciente do próprio propósito; fomentar cooperação nacional; tornar o ambiente imediatamente mais seguro.

```bash

cp .env.example .env.local
npm run dev
```

Admin: senha em `ADMIN_PASSWORD`. Persistência v1 é overlay localStorage. Vídeo 3.5.10 entra pelo admin quando o ID existir.
